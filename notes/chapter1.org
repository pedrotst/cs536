* Q: How do we know how to find the recipient of a message
* A: By assigning addresses

* The procedure of deciding how to forward messages until it reaches its address is called routing
  
* Q: How can hosts share the network?
* A: Multiplexing
** Like time-sharing in the OS level
** It can be of three kinds
*** Synchronous time-division multiplexing (STDM)
**** Round Robing
**** In quantum 1, data from 1st flow is transfered
**** In quantum 2, data from 2nd flow is transfered
**** and so on...
**** Con: if no data is sent from flow x, then quantum x is wasted
*** Frequency Division Multiplexing (FDM)
**** Transmit on different frequencies
**** Con: not practical to add new frequencies
*** Statistical Multiplexing
**** Basically STDM but solving the "no data" problem
**** It only transfers when a node asks for a time-slice
**** Keeps the use fair by setting a maximum data limit
**** this data limit is called a _packet_
** This is why a switch stores the data
*** If it received more packets than the link can accommodated, what would happen with the data?
*** When a switch runs out of buffer it is said to be _congested_

* A brief linear algebra recap
** Linear independence
   A set of vectors {v1, v2, ..., vn} is said to be linear independent if the equation
                      x1 * v1 + x2 * v2 + ... + xn * vn = 0
   has only the trivial solution.
  
*** trivial here means that x1, ..., xn are all 0.
   

** Ortogonality 
   Two vectors v1 and v2 are orthogonal if their dot product sums to zero
                                  v1 ⊙ v2 = 0
