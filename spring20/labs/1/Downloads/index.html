  • In Problem 2 of lab2, when the server decides to drop a client request, closing the server-side socket (full association socket returned by accept()) can result in select() returning 1 at the client. To determine whether select() returned 1 due to server-side connection close or because data has been received, perform read(). If read() returns 0, this implies that the server has closed its end. The client then can close its side of the connection and start anew.
  • In Problem 3 of lab2, please run the client, myftp, without the server's IP address (srv-ip) and port number (srv-port) as command-line arguments. Instead, run "% myftp cli-ip dropwhen" where cli-ip is the IP address to be used by myftp. The client finds out the server's IP address and port number upon receiving the first packet from the server using recvfrom(). myftp outputs its port number to stdout so that it can be used as part of the command-line arguments of myftpd.
